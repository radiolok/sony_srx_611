# SRX-C61 whole-system emulator (MAME driver)

A [MAME](https://www.mamedev.org/) driver, `sony/srx_c61`, that models the Sony
SRX-611 SCARA robot controller and runs the original firmware of every board:
CPU (i486), SERVO (V810), Control board (2× ADSP-2115). See
`doc/emulator_plan.md` for the plan, board models and milestones.

**Current state: stage 0 (skeleton).** All four CPUs are declared, the firmware
is loaded, and the known RAM/ROM regions are mapped; everything else is an
unmapped access that MAME logs (the "trace stub" of plan §7). Verified: the
i486 boots from the boot-EPROM reset vector, the V810 starts from `ROM_SERVO.bin`
and the two ADSP-2115s run their boot loader.

## Layout

| Path | Purpose |
|---|---|
| `src/mame/sony/srx_c61.cpp` | the MAME driver (single file) |
| `build.sh` | host build (`--docker` for the container build) |
| `Dockerfile` | multi-stage container build |
| `docker-entrypoint.sh` | container entrypoint |
| `make_roms.sh` | copy `FW/*` into `roms/srx_c61/` |
| `roms/srx_c61/` | ROM set (generated by `make_roms.sh`, git-ignored) |

## Build and run (Docker, recommended)

```sh
cd emu
./make_roms.sh                              # build the ROM set from FW/
docker build -t srx-c61-emu .               # build the image (pinned MAME mame0289)
docker run --rm srx-c61-emu                 # headless boot (SDK dummy driver)
```

Pass MAME arguments after the image name:

```sh
docker run --rm srx-c61-emu srx_c61 -seconds_to_run 5 -log -oslog   # 5 s run + trace to stdout
docker run --rm srx-c61-emu srx_c61 -video soft -window             # graphical window
```

Build-time options:

```sh
docker build --build-arg MAME_VERSION=mame0289 --build-arg MAKE_JOBS=8 -t srx-c61-emu .
```

## Build and run (host, no Docker)

Needs `build-essential git python3 libsdl2-dev libsdl2-ttf-dev`:

```sh
cd emu
./build.sh
"$HOME/opt/mame/mame" -rompath roms srx_c61 -video none -sound none -nothrottle
```

`MAME_DIR` and `MAME_VERSION` select the checkout and release.

## Notes

- The build uses `SOURCES=src/mame/sony/srx_c61.cpp` and `REGENIE=1`, so only the
  driver plus the MAME core and required devices are compiled (fast, small binary).
- Qt debugger is disabled (`USE_QTDEBUG=0`) and audio backends are disabled so no
  Qt/portaudio/pulse/pipewire headers are needed.
- The firmware images are the source of truth in `FW/`; `make_roms.sh` flattens
  them to the short names the driver's `ROM_START` declares.
